# 3-5 分钟 Pitch

## 0:00-0:35 问题

“《绝区零》约每 42 天更新一次。发行团队面对的不是一个玩家，而是多个语言社区、平台和利益相关者网络。今天，一个调整发布后只能靠经验判断要不要解释、补偿或回退。我们做的不是舆情自动摘要，而是一个发行前的社会压力测试沙盘。”

## 0:35-1:05 一周目与二周目

“一周目是各地区看帖子、开会、给严重度。二周目是把 125 个合成利益相关者放进同一个 42 天版本周期，让个人、群体、地区、国家、国际五层级在经济、政治、文化、社会和互联网五领域中互动。我们同时跑沉默对照和当前策略，并做 100 次扰动。”

## 1:05-2:25 Demo

1. 展示默认的“角色机制修复回退”。指出沉默峰值与快速纠正峰值的差异。
2. 把透明度拉到 0，观察第 42 天残余风险上升。
3. 缩短或拉长公开回应延迟，说明这是 42 天周期中的可操作决策。
4. 打开“群体地图”，指出结果是模型情景指数，地区默认参数相同。
5. 打开“证据库”，展示六个理论 DOI 和 B/C 级历史案例。

关键话术：“这里没有假装 41.1% 是现实概率。它只表示在同一组假设下，这套方案比沉默好多少。”

## 2:25-3:20 Injective 闭环

“发布风险判断最容易在事后被改写。我们把完整参数做 SHA-256，只把哈希和 1-5 档风险写到 Injective EVM Testnet。合约接收一个很小的 test INJ 验证脉冲并在同一交易退回。前端不碰私钥，而且会比对链上运行时代码，避免把代币发到错误地址。”

现场操作：连接 MetaMask，展示 Chain ID 1439、已核验合约地址、情景哈希和 Blockscout 交易链接。

## 3:20-4:00 价值与边界

“这个 MVP 的价值不是替发行负责人拍板，而是在发布前强迫团队写清假设、比较方案、留下证据和时间戳。现在只完成了可解释的合成代理与一轮校准；下一步是接入更多可验证历史样本做盲回测，并让地区参数只从公开证据学习。”

## 备用问答

- 为什么不用大模型直接预测？大模型会给出流畅但难审计的单点答案；当前 MVP 优先保证可复现和可解释。
- 125 人是否代表真实玩家？不代表。它是百人级压力测试规模，不是抽样调查。
- Injective 为什么必要？它固定发布前假设和结果摘要，为版本后复盘提供不可事后修改的审计锚点。
- 测试 INJ 有什么价值？没有经济价值，只用于证明真实钱包、真实网络和真实合约路径已经跑通。
