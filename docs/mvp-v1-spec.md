# 比赛 Mac MVP 规格 v1.1

状态：已冻结默认垂直切片；赛前采用 MVP 的 MVP 路线，完整能力目标移入赛后迭代

决定日期：2026-07-24

## 一句话产品

在当前 macOS 演示机上，把固定的一组公开多语言发行材料编译成一个有引用、有假设标记、可复现的 42 天社会压力测试；让发行负责人比较两套应对策略，查看哪些机制、群体和时间窗口造成差异，并在用户确认后把运行摘要提交到 Injective 测试网核验。

系统回答的是“在这些证据与假设下，策略如何分叉”，不是“现实危机发生概率是多少”。

## 默认垂直切片

- 游戏环境：《绝区零》。
- 历史复演：1.4 “特定视角下代理人渐隐”调整、部分情况下显示不正确、官方修复，以及公开出现的“已付费或解锁内容仍被限制观看”frame。
- 历史边界：官方公告没有说明完全撤销渐隐调整；300 菲林对应同一公告列出的四项问题，不能写成渐隐问题的单项补偿；一条媒体报道只能证明拥有感 frame 公开出现过，不能证明其代表多数玩家。
- 3.1 产品环境：HoYoverse 官方福利页写明，参与活动“恰浪花逐夏而至”可免费领取露西泳装“公主假日”。该信息只证明产品环境。
- 合成事件：假设 3.1 上线后该时装在超出预期边界的视角中异常渐隐，并出现内容访问或拥有感受限的公开讨论。它没有发生过，必须始终标记为 `synthetic-counterfactual`。
- 基线策略：延迟且边界模糊的回应。
- 候选策略：快速说明预期边界、发布纠正进度、明确补偿范围、保持中英日语义一致并在修复后复盘。
- 周期：42 天。
- 群体：125 个合成代表者，不对应真实个人，也不宣称人口代表性。
- 语言目标：中文、英文、日文。当前已有中英文案例材料，日文直接证据与三语语义比较尚未达标。
- 研究时点：2026-07-24。3.1 计划于 2026-07-29 上线，因此任何 3.1 上线后行为、争议或风险都不是已知事实。

默认配置位于 `data/scenarios/zzz-3-1-fade-risk-vertical-slice.json`。`data/scenarios/zzz-tv-mode-vertical-slice.json` 是早期 TV Mode 技术切片，只保留作回归与历史参考。

## 当前阶段闭环

本阶段已经打通“公开证据到可供编译的 Theory System”，但尚未打通真实模型到多 Agent 推演：

1. 三份人工批准的提取结果分别覆盖 1.4 官方公告、拥有感 frame 的媒体记录和 3.1 官方时装信息。
2. `evidence-review/1.0` 对每份提取结果做 SHA-256 绑定，并把批准的 proposal 解析到证据账本 Claim；内容变化后旧审批失效。
3. Theory System Agent 在 11 项闭集理论目录中提议映射并执行确定性审计。无法负责映射的 Claim 会进入目录缺口状态，不自动发明理论。
4. Agent 在 `AWAITING_HUMAN` 暂停，人工逐项选择批准、退修或拒绝；只有批准后恢复运行才能生成内容寻址的 `theory-system:sha256:*`。
5. 情景编译器只接受批准的 Theory System ID 和映射路径，不能绕过人工审批直接选理论或参数。

当前仓库内闭环使用确定性映射夹具，`realModelUsed: false`。这证明状态机、审计和审批契约可运行，不证明真实模型已经参与理论映射或情景编译。

## 赛前端到端用户路径

1. 发行分析员选择一组公开材料或输入公开 URL。
2. 系统保存标题、网站、URL、发布时间、访问时间、语言、来源等级和短摘录。
3. AI 提取事实、争议框架、利益、立场和历史类比；提取结果先进入人工 Evidence Review，不能直接成为事实。
4. Theory System Agent 使用 11 项白名单理论目录提出机制映射，经确定性审计和人工逐项审批后形成内容寻址 Theory System。
5. AI 只能在批准 Theory System 的 Claim、构件和参数路径内编译结构化情景；每个数值必须绑定证据或显式合成假设。
6. 现有确定性推演把已验证的结构化情景传播到 125 个合成代表；赛前不新增 AI 锚点决策、长期记忆或关系涌现。
7. 同一合成人群、同一种子分别运行基线与候选策略 42 天，并执行配对敏感性扰动。
8. 现有 3D 观察器回放已存在的立场、压力、完整度和可用聚合通道；缺失的 Reverse、关系与事件通道继续明确标空。
9. 系统给出带证据的差异解释，不输出现实概率。
10. 运行清单、证据包、模型版本、seed、策略和结果形成摘要哈希，只在用户确认后提交 Injective 测试网。

## AI 与确定性模型的分工

AI 负责：

- 多语言文本中的事实、立场、利益与框架提取。
- 闭集社会学理论候选匹配；人工复核和内容寻址负责决定映射是否可进入编译。
- 证据包到结构化情景的编译。
- 对确定性结果做引用受限的自然语言解释。

确定性模型负责：

- 125 个合成代表的逐日数值状态更新和既有多层传播。
- 基线与候选策略的共享人群、共享种子配对。
- 42 天回放、分层聚合和 P10/P50/P90 假设敏感性区间。
- 可复现产物与密码学摘要。

禁止让 LLM 直接生成最终风险概率，也不执行 `125 × 42` 次模型调用。

## 模型接入

- 接口：服务端 OpenAI-compatible Chat Completions。
- 密钥：BYOK，只从环境变量进入 Node 进程，不写入仓库或浏览器。
- 正式能力状态：只有成功完成真实请求并保留 provider、model、request ID 和验证通过的输出，才能标记 `realModelUsed: true`。
- 离线演示：允许回放真实调用保存的结构化输出，但必须显示 `recorded-model-output`；手写夹具不能冒充模型输出。
- 当前状态：适配器、验证器、Theory System 审批和编译门已实现并由测试覆盖；当前环境没有模型 Key，也没有真实模型编译产物。仓库内确定性 fixture 只能用于离线闭环演示。

## 证据规则

- A：官方页、原始论文、DOI 元数据，可用于事实和理论定义。
- B：可直接读取的专业媒体原创报道，可用于历史类比，但保留转述误差。
- C：搜索索引、无法直接读取的页面或社区线索，只进入研究队列。
- F：无来源或冲突来源，不进入默认 Demo。

默认 AI 证据包拒绝 C/F Claim。合成假设不进入证据账本，必须在编译产物的 `assumptions` 和 `parameterBindings` 中单独列出。任何不等于 `1.0` 的地区系数必须由直接证据绑定，不能来自刻板印象。

## 比赛 Mac MVP 完成门槛

| 能力 | 验收证据 | 当前状态 |
| --- | --- | --- |
| 机器证据账本 | 来源元数据、Claim 反向引用、C/F 默认拒绝、自动测试 | 已完成基础版；三语语义比较未完成 |
| 学术理论库 | 11 个有学术来源的构件、启用条件、允许参数路径和局限 | 已完成本切片基础版：6 核心 + 5 条件 |
| Evidence Review | 提取摘要、proposal 到 Claim 的人工决定、内容变化失效 | 已完成本切片闭环 |
| Theory System Agent | 闭集映射、确定性审计、人工暂停/退修/拒绝、内容寻址、编译门 | 已完成离线夹具闭环；`realModelUsed: false` |
| 真实 AI 情景编译 | 真实模型请求、结构化产物、无虚构引用、参数绑定全部通过 | 未完成：无模型 Key |
| 百人级确定性推演 | 复用 125 个合成代表、共享种子策略对照和可复现 42 天 trace，并明确非认知 Agent | 已完成技术基线；赛前只做接线与边界校验 |
| 策略对照与不确定性 | 共享种子配对、机制解释、敏感性区间、最小历史校准评测 | 部分完成：旧公式版 |
| 3D 演化展示 | 在 Mac 上复用现有回放，展示可用通道并把 Reverse、关系边与事件等缺失通道标空 | 已完成技术基线；赛前不新增涌现通道 |
| Injective 闭环 | 已部署地址、receipt、`RiskCommitted` 事件读回、浏览器公开链接 | 未完成：只有交易编码骨架 |
| 现场交付 | 当前 macOS 演示机、无网缓存模式、3–5 分钟路径、模型卡、本地三门测试报告、单一 macOS PR 复验记录与提交说明 | 未完成 |

只有表中赛前能力都有直接验收证据，项目才可以称为“比赛 Mac MVP”。它不能被称为通用跨平台产品、混合认知 Agent 社会或能力涌现系统。

## 赛后能力迭代

- 具备立场、目标、长期记忆、关系与公开表达的混合认知 Agent。
- AI 锚点决策与确定性传播结合后的群体能力涌现评测。
- 新运行时驱动的 Reverse 声量、关系边和事件通道。
- 多案例、任意公开输入与直接地区证据扩展。
- 非 macOS 平台适配、CI 操作系统矩阵、浏览器兼容验证和跨平台复验。

## 明确不做

- 不预测真实玩家、国家或地区的行为概率。
- 不模拟或冒充真实个人。
- 不抓取私有数据，不要求社区账号登录。
- 不把社媒讨论量当作全体玩家比例。
- 不让区块链参与社会计算或承载大体积语料。
- 不用测试代币构造博彩、投机或有经济价值的预测市场。
- 赛前不承诺非 macOS 平台、跨平台 CI 或跨平台复验。
- 赛前不把现有数值代理包装为混合认知 Agent、关系涌现或真实群体能力涌现。
