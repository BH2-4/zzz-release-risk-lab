# Beta 0.3：把单条回放与假设敏感性分开

日期：2026-07-23

状态：可复现数据产物已生成

## 这轮解决什么

Beta 0.2 的 3D 棋盘可以连续回放 125 个合成 Agent 的 42 天变化，但只有一组固定参数和随机种子。它适合解释一次运行如何演化，不能说明结论对模型假设是否敏感。

Beta 0.3 保留这条逐 Agent 代表性路径，同时增加 100 组配对运行。每一组里的沉默方案和候选方案共享情景扰动、合成人群和模拟种子，减少无关随机差异。

## 历史原型与应用边界

- 历史原型：Genshin Impact 4.8 角色机制修复后回退。
- 应用环境：合成的《绝区零》发行情景，不声称相同事件已在《绝区零》发生。
- 证据等级：B 级专业媒体转述。
- 模型参数：研究者假设，未由历史数据校准。

来源：米哈游《原神》道歉：角色技能问题修复后回退、补偿 1600 原石，IT之家，2024-07-18，https://www.ithome.com/0/782/509.htm

## 100 组配对运行结果

| 第 42 天情景指数 | P10 | P50 | P90 |
| --- | ---: | ---: | ---: |
| 延迟最小响应 | 30.86 | 34.31 | 37.28 |
| 回退、解释与补偿 | 7.01 | 9.59 | 12.78 |
| 候选减去基线 | -25.82 | -24.57 | -23.12 |

这些数值说明候选策略在当前有界假设中始终更低；它们不证明现实中会降低同等幅度，也不是统计置信区间或现实概率。

## 前端如何使用

- 3D 棋子回放固定种子路径，表现第 1 天到第 42 天的连续演化。
- 聚合 P10/P50/P90 通过独立契约提供，统一称为“假设敏感性区间”。
- Agent 级区间、关系边、Reverse 声量与 Reverse 热度仍不可用，前端不得补画。
- 浏览器先校验清单字节长度与 SHA-256，再创建 Three.js 场景；它不在页面内重新运行模型。
