# Beta 0.4：逐日观察宏观与微观结构

日期：2026-07-23

状态：可复现数据产物已生成

## 为什么继续处理数据

Beta 0.3 已能回答“整体风险区间如何随 42 天变化”，但层级、领域和地区只有第 42 天切片。3D 前端若要表现整个行进过程，就还需要知道每一天哪些结构先升高、何时回落，而不能从单条棋子路径推测集合稳定性。

Beta 0.4 因此增加逐日分层假设敏感性：

- 42 天。
- 层级、领域、地区三条轴。
- 每条轴五个分组。
- 沉默、候选、差值三种策略视图。
- P10、P50、P90 三个分位值。

共增加 `42 x 3 x 5 x 3 x 3 = 5,670` 个数值。产物由 1,086,202 字节增至 1,114,237 字节，增加约 2.6%。

## 可观察到的代表性路径

以下只列候选响应方案的 P50 情景指数：

| 时点 | 层级较高项 | 领域较高项 | 解释边界 |
| --- | --- | --- | --- |
| 第 25 天事件日 | 群体 43.61、地区 43.45 | 互联网 54.82、经济 48.62 | 来自当前触发强度假设 |
| 第 26 天响应开始 | 群体 21.39、地区 21.15 | 互联网 33.02、经济 26.68 | 表示模型中的即时缓冲 |
| 第 42 天 | 群体 11.45、地区 11.17 | 互联网 18.92、经济 14.63 | 仍有模型残余压力 |

模型没有输入地区差异系数。因此地区间出现的细小排序来自合成人群和扰动，不能解释为某个地区更敏感，也不应在前端生成地区风险排名结论。

## 给后续 3D 前端留下的接口

- `decodeSensitivitySegmentDay(bundle, { view, axis, day })`：读取某一天的五个分组区间。
- `dailySegmentBands: true`：表示逐日分层数据可用。
- `perAgentBands: false`：棋子仍是一条固定种子代表性回放。
- `relationEdges: false`：不得绘制虚构传播关系。
- `reverseVoice: false`、`reverseHeat: false`：Reverse 仍只能保持未接入状态。

前端可据此增加“层级 / 领域 / 地区”的时间联动视图，但不能把聚合区间涂到单个棋子上。

历史原型仍为 Genshin Impact 4.8 角色机制修复后回退；应用环境仍是合成的《绝区零》发行情景。历史事实为 B 级专业媒体转述，触发强度和响应系数是研究者假设。
