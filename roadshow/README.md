# 商业路演版本

本目录独立保存面向评委和业务负责人的商业路演，不与模拟器产品页混放。新一轮路演应创建新版本目录，保留旧版本供对照和回滚。

## 当前版本

### Beta 0.1

- 定位：面向《绝区零》海外发行负责人的 3-5 分钟评审路演。
- 主张：在版本上线前，先把危机走一遍。
- 演示：[`beta0.1/index.html`](beta0.1/index.html)
- 讲稿：[`beta0.1/speaker-notes.md`](beta0.1/speaker-notes.md)
- 状态：可排练、可现场播放，尚未标记为正式版。

## 版本规则

- `beta0.x`：可快速迭代内容和表达，但不对外声称为最终版。
- 新版本创建独立目录，不覆盖已经用于排练的版本。
- 每个版本至少包含可播放的 `index.html` 和对应讲稿。
