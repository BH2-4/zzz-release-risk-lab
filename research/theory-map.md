# 社会学理论库索引

更新时间：2026-07-24

机器目录：`data/evidence/theory-catalog.json`

本项目不把“引用了理论”当作科学性。每个理论必须同时给出原始来源、适用条件、公开可观察量、允许进入的模型路径和禁止声称；模型只能从白名单中提议，最终选择必须由人批准。

## 文件导航

- [核心理论栈](theory-library/core-stack.md)：六个默认机制及其顺序。
- [条件理论模块](theory-library/conditional-modules.md)：只有满足证据条件时才启用的五个模块。
- [学术来源登记表](theory-library/source-register.md)：题名、出版社、DOI、发布时间与核验等级。
- [建模与推断边界](theory-library/modeling-boundaries.md)：什么能进入 Demo，什么绝对不能声称。

## 当前最小栈

```text
公开文本的 Frame
  -> SCCT 责任与回应
  -> STOPS 个体情境判断
  -> Threshold 公开参与激活
  -> SMCC 渠道与来源传播
  -> SARF 跨层放大、衰减和次生影响
  -> 官方回应反馈到 SCCT
```

条件模块不与核心栈争夺主动力学：沉默螺旋只负责“私下立场到公开表达”的门，相对剥夺只处理明确的比较与不公，利益相关者显著性只服务发行决策优先级，连接行动只处理持续的去中心化协调，Image Repair 只编码官方回应话语。
