# 模型卡

版本：垂直切片 v1

更新时间：2026-07-24

## 目的

帮助全球发行团队在 42 天版本周期内比较多个应对方案，识别在不同假设下仍然稳定的风险来源、关键群体和时间窗口。

当前默认任务不是泛化的《绝区零》危机预测，而是复演 1.4 “特定视角渐隐”事件，再对 3.1 露西时装执行一个明确标注的合成反事实压力测试。以本模型卡研究时点计，3.1 尚未上线。

## 不是做什么

- 不预测现实危机是否会发生。
- 不估计真实玩家、地区或国家的行为概率。
- 不替代用户研究、法务、公共政策或本地文化专家。
- 不给国家、族群、语言或文化群体贴固定风险标签。

## 当前输入

- `evidence-ledger/1.0` 公开来源、Claim、语言、证据等级与定位信息。
- `evidence-review/1.0` 人工审核结果，以及每份提取制品的 SHA-256 摘要。
- `theory-catalog/1.0` 的 11 项理论构件、启用条件、允许映射路径与局限。
- `theory-system/1.0` 人工批准、内容寻址的 Claim 到理论机制映射。
- `compiled-scenario/1.0` 中证据绑定和显式合成假设。
- 事件日、可控性、既往危机强度。
- 经济、政治、文化、社会、互联网五领域触发强度。
- 显式地区系数，缺省全部为 `1.0`。
- 响应延迟、透明度、参与、补偿、本地化、纠正行动。
- 合成角色的阈值、易感性、影响力、制度信任与网络活跃度。

3.1 露西时装来自 HoYoverse 官方福利页，是产品环境输入。渐隐异常、公开争议、传播强度和策略效果都是合成假设，不能由这条官方事实推导。

## 当前可用输出

- 经人工 Evidence Review 的 1.4/3.1 Claim 集合与输入摘要。
- 经确定性审计和人工逐项批准的 Theory System，ID 为 `theory-system:sha256:*`。
- Theory System 对本切片四条 Claim 的完整覆盖、理论构件、允许参数路径和局限。

### 旧公式引擎产物

以下数值与可视化产物尚未由真实模型编译或真实多 Agent 运行时驱动：

- 42 天风险指数曲线。
- 峰值与第 42 天指数。
- 五层级、五领域、五地区拆分。
- 方案差值。
- 100 组配对运行的整体逐日与第 42 天 P10/P50/P90 假设敏感性区间。
- 42 天内五层级、五领域、五地区的逐日 P10/P50/P90 假设敏感性区间。
- 一条固定种子的逐 Agent 代表性回放，供 3D 演化观察器使用。

以上数值输出是情景指数和参数敏感性，不是预测概率。当前新的渐隐切片已进入 Theory System 与编译门，但尚无真实模型编译后的 42 天运行产物。

## 数据状态

- 学术构件：11 项来源已登记，包括 6 项核心理论与 5 项条件理论；理论名称本身不提供效应量。
- 默认历史案例：1.4 官方 X 公告（A）与游民星空媒体记录（B）；足以固定机制和话语边界，不足以校准预测准确率。
- 3.1 产品环境：HoYoverse 官方福利页（A）确认露西泳装“公主假日”可通过指定活动免费领取；IT之家（B）仅作旁证。
- Evidence Review：已人工批准三份提取并解析四条进入理论映射的 Claim；提取内容由 SHA-256 绑定。
- Theory System Agent：已完成离线提议、审计、人工审批、恢复和内容寻址闭环；当前运行 provenance 为 `deterministic-fixture`，`realModelUsed: false`。
- 群体：125 个完全合成角色，不代表真实人群。
- 地区：无默认差异，防止把刻板印象藏进代码。
- AI：已有服务端 OpenAI-compatible 适配器、闭字段校验、批准 Theory System 编译门和 provenance 检查；当前没有真实模型编译产物，因此不可称为 AI 驱动完成态。
- Agent：尚未实现具备立场、目标、记忆、关系和公开表达的真实多 Agent 运行时。

## 主要风险

1. 参数由研究者设定，可能把主观判断伪装成数学精度。
2. 大规模平均会掩盖少数高影响群体。
3. 公开社区数据存在活跃用户偏差、语言偏差和平台选择偏差。
4. 历史事件之间不可直接类比，理论映射不等于因果证明。
5. LLM 生成的角色叙事可能强化刻板印象，因此核心计算只使用有限数值字段。
6. 单个棋子只代表固定种子合成路径；当前没有 Agent 级区间，不能将其解释为现实个体预测。
7. 未输入地区证据系数时，地区间的小幅差异来自合成样本与扰动，不能解释为地区特征。
8. 单个历史案例只能支持机制合理性复演，不能支持跨版本效应量或 3.1 危机发生判断。

## 发布门槛

- 界面始终显示“情景指数，不是现实概率”。
- 参数修改与结果哈希可复现。
- 证据等级与来源对用户可见。
- C/F 级案例不用于现实结论。
- 至少完成三组历史留出回测后，才讨论预测性能；在此之前只比较策略稳健性。
- 只有 `provenance.mode = live-model` 的验证产物才证明真实模型已经接入；测试 mock 和手写夹具不算。
- 录制回放必须显示 `recorded-model-output`，不得冒充现场调用。
- 确定性映射夹具必须显示 `deterministic-fixture` 和 `realModelUsed: false`，不得冒充真实模型理论映射。
- 3.1 官方时装信息只能作为产品环境；界面和路演不得暗示官方材料证明渐隐、争议或危机将发生。
