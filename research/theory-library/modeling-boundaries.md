# 建模与推断边界

更新时间：2026-07-24

## 允许做的事

- 用一个历史事件检查机制是否具有合理性、方向是否一致、响应时序能否回放。
- 把理论构件变成有名称、有范围、有来源的合成变量。
- 在同一证据、同一合成人群和同一种子下比较两套发行策略。
- 对合成参数跑 ensemble，淘汰只在极窄假设下成立的策略。
- 明确列出理论目录缺口并停止自动编译。

## 不允许做的事

- 用单一历史事件校准“真实危机概率”或跨版本通用效应量。
- 把社区发帖者当作全体玩家，把互动量当作支持率。
- 从公开表达推断沉默者、地区人口或国家意见。
- 让模型自动增加学术理论、构件、参数路径或 effect size。
- 将 3.1 尚未发生的事件写成预测事实。
- 只凭理论名称生成数值；每个数值仍需证据绑定或显式合成假设。

## 历史复演到 3.1 的规则

1. 先在 1.4 事件中冻结可观察机制结构。
2. 分开保存历史事实、媒体转述、社区解释和研究者假设。
3. 到 3.1 时只替换事件输入和合成参数，不回头改理论结构来追求预设结果。
4. 所有 3.1 风险输出称为“合成反事实压力测试”，不得称为危机概率或真实预测。
5. 输出必须展示假设敏感性和无法从公开数据识别的变量。
