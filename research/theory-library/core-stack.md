# 核心理论栈

更新时间：2026-07-24

## 1. Framing

回答“大家在争论什么”。把公开文本拆成问题定义、因果归因、道德评价和处理建议。Demo 可以统计不同语言、渠道、日期中的 frame，但不能从 frame 推断多少玩家相信它，也不能直接生成风险系数。

在 1.4 渐隐事件中，可比较“异常显示修复”“镜头自由受限”“审查感知”“付费或拥有感受损”等竞争性定义。它们是可编码的话语，不是真实群体比例。

## 2. SCCT

回答“玩家把责任归给谁，回应是否匹配”。输入包括危机类型、可控性感知、既往历史、回应延迟，以及解释、道歉、纠正、补偿等动作。SCCT 只帮助构造策略对照，不提供《绝区零》专属效应量。

## 3. STOPS

回答“一个合成代表者为什么开始找信息、筛选信息或分享信息”。核心是问题识别、约束识别、涉入识别、既有判断标准和情境动机。公开帖子只能给出这些变量的线索，不能识别未发言玩家的真实心理。

## 4. Threshold

回答“为什么声量会突然越过临界点”。每个合成代表者拥有异质参与阈值；已参与比例越过阈值后才进入公开行动。单一事件曲线无法唯一反推出真实玩家阈值分布，因此 Demo 必须跑合成参数的敏感性组合。

## 5. SMCC

回答“信息从谁那里、以什么形式、在哪个渠道流动”。它将官方账号、媒体、创作者、普通社区用户等来源角色与信息寻求、分享、跨平台迁移和过载分开。互动量只能是公开渠道代理，不能当支持率。

## 6. SARF

回答“一个信号如何从个人扩展到群体、地区和国际层，并产生次生议题”。个人、社区、媒体和机构可作为放大或衰减站。SARF 是跨层结构，不提供通用放大系数；声量放大也不等于客观危害变大。

## 数据流

| 阶段 | 输入 | 输出 | Demo 中的职责 |
| --- | --- | --- | --- |
| Framing | 公告、媒体、社区文本 | 竞争性问题定义 | 形成内容特征 |
| SCCT | 责任归因、危机历史、回应 | 回应策略向量 | 建立基线与候选策略 |
| STOPS | 情境判断线索 | 寻求/分享倾向 | 更新合成代表者状态 |
| Threshold | 异质阈值、已激活比例 | 是否公开参与 | 产生非线性激活 |
| SMCC | 来源、渠道、关系边 | 跨渠道转移 | 传播公开信号 |
| SARF | 多层节点与信号 | 放大、衰减、次生影响 | 形成 42 天跨层演化 |

所有数值初值都必须注明 `synthetic-assumption` 或来自以后完成的历史校准；理论名称本身不能充当数值证据。
