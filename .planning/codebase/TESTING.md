# Testing Patterns

**Analysis Date:** 2026-07-24

## Test Framework

- Unit/integration runner: Node built-in `node:test` through `npm test`.
- Assertions: `node:assert/strict`; tests use `test(...)` with descriptive behavior names.
- E2E runner: Playwright 1.61.1 with desktop Chrome and Pixel 5 projects.
- Contract compiler: solc is exercised by `npm run build` and `tests/contract.test.js`.

## Required Stage Gate

Every GSD phase must run all three commands before it can be marked complete:

```bash
npm run build
npm test
npm run test:e2e
```

A phase remains incomplete if any command fails. No known-failure exemption may be relabeled as a completed phase.

## Test Organization

- `tests/*.test.js` covers pure modules, CLI boundaries, deterministic artifacts, browser module exports, and contract behavior.
- `tests/e2e/dashboard.spec.js` covers dashboard controls, mocked wallet flows, pitch viewports, 3D replay, pixel checks, and mobile overflow.
- Shared checked-in fixtures live in `data/` or `experiments/fixtures/`; per-test temporary attack inputs use the Node test context and OS temp directories.

## Unit and Integration Patterns

- Import CommonJS APIs with `require` and use `assert.equal`, `assert.deepEqual`, `assert.throws`, or `assert.rejects`.
- Test deterministic behavior with fixed seeds and compare generated bytes/manifests to checked-in outputs.
- Mutation and tampering tests clone artifacts before modification and verify rejection at the next trust boundary.
- CLI tests call exported `runCommand` functions when possible; they verify error types/messages and filesystem side effects.
- Security regressions must attack temporary copies, never authoritative `data/evidence/ledger.json` or approved artifacts.

## Browser Patterns

- Playwright starts `python3 -m http.server 4173` using `playwright.config.js`.
- Wallet tests inject a fake `window.ethereum` before page load and assert exact method order and transaction shape.
- 3D tests inspect canvas bounds and `window.__evolutionDiagnostics.pixelStats()` to detect blank rendering.
- Viewport tests assert no overflow and save screenshots under ignored `artifacts/screenshots/`.
- Do not use a real wallet, testnet transaction, or model provider in automated tests.

## Coverage

- `npm run test:coverage` uses Node's experimental coverage reporter.
- No numeric coverage threshold is configured; risk-based regressions and trust-boundary coverage are the operative standard.
- The current suite contains 124 Node tests plus Playwright journeys; six Node failures are intentionally exposed regressions in `tests/theory-agent-cli.test.js` and block completion.

## Current Red Tests

- Deterministic fixture path and SHA-256 provenance are missing.
- Input realpath escape and output-parent symlink protections are missing.
- Temporary output is fixed by PID rather than random exclusive creation.
- Theory Agent output can overwrite a validated input.
- Malformed JSON errors reveal parser detail that must be redacted.

## Test Addition Guidance

- Add a failing regression first for bug fixes, then make the smallest implementation change.
- For research changes, test both allowed use and forbidden inference boundaries.
- For replay changes, test schema/capability compatibility, deterministic bytes, and visible browser behavior.
- For chain changes, test validation and mocked wallet calls only; deployment remains a separately confirmed manual UAT.
