<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| checked inputs -> regenerated run | Input digest drift must invalidate the old run and bind the new one. |
| local review command -> approval lineage | Reviewer text is a declaration; authority comes from explicit review target and event/digest lineage. |
| generated run -> docs/compiler | A stale or manually edited ID must not be promoted as current authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-REGEN-S | Spoofing | stale run/ID | high | mitigate | Replace authority only through the complete CLI lifecycle and exact current input digest validation. |
| T-01-REGEN-T | Tampering | generated JSON | high | mitigate | Prohibit manual edits; reconstruct Theory System and verify content/event/review digests through tests. |
| T-01-REGEN-R | Repudiation | local review lineage | medium | mitigate | Bind reviewer, reviewedAt, mapping decisions, target digest, and monotonic event revisions in the run. |
| T-01-REGEN-I | Information Disclosure | status/docs | low | accept | Status and handoff contain artifact IDs and non-secret provenance only; no credentials or provider payload exists. |
| T-01-REGEN-D | Denial of Service | stale/mismatched inputs | medium | mitigate | Fail regeneration/validation on any input digest or timestamp mismatch rather than emitting a partial READY artifact. |

</threat_model>
