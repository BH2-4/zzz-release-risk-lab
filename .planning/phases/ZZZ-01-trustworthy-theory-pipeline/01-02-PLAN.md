<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv/env paths -> project filesystem | User-controlled relative paths may traverse, alias, or pass through symlinks. |
| protected inputs -> run output | A writable run path must never replace evidence, review, catalog, fixture, or their aliases. |
| parsed JSON -> public CLI error | Malformed contents may contain credentials or marker strings that cannot be reflected. |

This local single-user MVP treats project CLI writers as cooperating actors: every writer of a Theory run directory must acquire the inherited parent-directory `flock` before mutation. A non-cooperating same-UID process already has equivalent authority over the project tree and is outside this plan's threat model. The implementation therefore makes no claim of universal safety against hostile concurrent filesystem mutation.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-PATH-T | Tampering | path/collision checks | high | mitigate | Resolve real root/inputs, reject symlink chains/targets, and compare canonical paths plus device/inode before provider access. |
| T-01-PATH-E | Elevation of Privilege | temp/rename boundary | high | mitigate | Use same-directory random `wx` temp with 0600, fsync/close, recheck, rename, and cleanup. |
| T-01-PATH-I | Information Disclosure | JSON error wrapper | high | mitigate | Emit artifact label and safe path context only; discard raw parser messages and file contents. |
| T-01-PATH-S | Spoofing | path aliases | medium | mitigate | Treat lexical, canonical, symlink, and same-inode aliases as one protected artifact identity. |
| T-01-PATH-D | Denial of Service | invalid local paths | low | accept | Invalid paths terminate one local command with a bounded error; no shared service or persisted partial state exists. |

</threat_model>
