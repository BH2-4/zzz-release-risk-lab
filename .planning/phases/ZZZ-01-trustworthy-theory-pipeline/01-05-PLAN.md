<threat_model>
## Boundary And Scope

This is a local, single-user, Mac-only competition MVP. Project writers are cooperative and must obey the existing parent-directory `flock` contract before mutating a Theory run directory. A non-cooperating same-UID process that can arbitrarily alter the project tree remains an explicit residual risk. This plan does not attempt universal hostile-filesystem transactions, new private syscalls, Windows/Linux portability, an operating-system matrix, or cross-platform verification.

## Trust Boundaries

| Boundary | Risk | Required control |
|----------|------|------------------|
| persisted run + current reviewed inputs -> `status` | stale/tampered bytes are presented as authoritative | secure current-input load, input-authoritative validation, exact READY rebuild, summary only after success |
| persisted pending mapping -> `review` | recomputed structural digests permit false approval | validate against current inputs before creating or persisting a review |
| approved mapping/review -> persisted Theory System | self-consistent content addressing hides semantic detachment | rebuild with `finalizeTheorySystem` and compare the complete canonical artifact |
| review history -> event history | recomputed reviews contradict recorded transition state | closed review normalization plus decision/state/target/event binding |
| validator failures -> CLI stderr | attacker-controlled semantic values leak from detailed errors | stable artifact-safe public error with no raw content or secret marker |

## STRIDE Register

| Threat ID | Category | Severity | Disposition | Mitigation |
|-----------|----------|----------|-------------|------------|
| T-01-05-S | Spoofing | high | mitigate | Current inputs and canonical reconstruction must validate before status or approval authority is exposed. |
| T-01-05-T | Tampering | high | mitigate | Recomputed mapping/System/review/event digests cannot substitute for semantic derivation and state agreement. |
| T-01-05-R | Repudiation | medium | mitigate | Each historical review is normalized and bound to its decision event and preceding proposal target. |
| T-01-05-I | Information Disclosure | high | mitigate | CLI authority failures use bounded constant errors; tests inject secret markers and assert non-reflection. |
| T-01-05-D | Denial of Service | low | accept | Invalid local artifacts terminate one command without output mutation; no service availability guarantee is added. |

## Residual Risk

- Same-UID writers that ignore the parent-directory flock can still alter project files and are out of scope.
- Reviewer names remain local declarations, not authenticated or cryptographic identities.
- Historical review payloads do not retain every prior mapping artifact; this plan validates their closed internal contract and event/target binding without claiming full historical mapping reconstruction.
</threat_model>
