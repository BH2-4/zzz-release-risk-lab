<threat_model>
## Offline Security Contract

- Standard: OWASP ASVS Level 2 controls are prepared and tested for provider parsing, fixed validation, and local publication; final ASVS L2 closure remains in 02-02 after the live artifact exists.
- Cooperative writer boundary: every compile output inspection, recovery, commit, and finalize operation is serialized by `LOCK_EX|LOCK_NB` on the already-open parent directory fd 3 through `secure-run-output.py`.
- Busy behavior: contention returns helper status `busy` and exit 76 without waiting, mutation, provider generation at preflight, target overwrite, corruption, or debris.
- Conflict behavior: expected target device/inode mismatch fails closed and preserves the concurrent owner's bytes; operation-owned recovery never deletes a foreign entry.
- Residual risk: a non-cooperating same-UID process that ignores flock and can arbitrarily alter the repository remains outside the contract. No universal hostile-filesystem safety claim is permitted.

| Threat | Severity | Required offline disposition |
|--------|----------|------------------------------|
| Provider/response spoofing | high | Exact MiniMax provider/model, body id, optional actual trace id, closed provenance, one mocked call. |
| Model/fixed-input tampering | critical | Canonical slice and Theory System digests before generation; exhaustive local validation after parsing. |
| Credential/reasoning disclosure | critical | No credentials in this plan; sentinel-safe errors and no prompt/raw/reasoning persistence. |
| Cooperative output contention | high | Parent-directory non-blocking flock plus expected-target identity and journal recovery tests. |
| Symlink/path redirection | critical | Existing project-contained no-follow parent fd, identity recheck, basename-only helper entries, protected-input checks. |
| External DoS/malformed output | medium | Timeout, bounded single parse, no retry/repair, no partial publication. |
| Chain/tool privilege escalation | high | No tools, wallet imports, signing, network switch, deployment, or transaction path. |
</threat_model>
