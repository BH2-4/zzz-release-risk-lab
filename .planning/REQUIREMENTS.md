# Requirements: ZZZ Release Risk Lab

**Defined:** 2026-07-24
**Core Value:** Every simulated divergence is traceable to reviewed public evidence or an explicit synthetic assumption.

## v1 Requirements

### Trust Baseline

- [ ] **TRUST-01**: Operator can run the Theory Agent CLI without any output path overwriting or escaping the reviewed project inputs.
- [ ] **TRUST-02**: Operator can distinguish deterministic fixtures, recorded model output, and live model output from complete provenance.
- [ ] **TRUST-03**: Operator can regenerate a READY Theory System whose digests and review lineage match the restored evidence ledger.
- [ ] **TRUST-04**: Maintainer can pass build, complete Node tests, and desktop/mobile E2E tests at every phase boundary.

### Evidence and AI Compilation

- [ ] **AI-01**: Analyst can compile the default scenario through one real OpenAI-compatible model request without exposing the BYOK credential to browser code or artifacts.
- [ ] **AI-02**: Every model-produced claim, theory, numeric parameter, and regional difference is accepted only when bound to approved evidence or an explicit synthetic assumption.
- [ ] **AI-03**: The resulting artifact records provider, model, request ID, source digests, Theory System ID, and validation status.
- [ ] **AI-04**: Evidence inputs support Chinese, English, and Japanese review without treating machine translation as equivalent to direct source evidence.

### Injective Audit

- [ ] **CHAIN-01**: User can deploy or select the exact `RiskCommitment` bytecode on Injective testnet only after explicit wallet confirmation.
- [ ] **CHAIN-02**: User can submit one bounded test-INJ commitment and verify its receipt and `RiskCommitted` event through a public explorer.
- [ ] **CHAIN-03**: Repository records contract address, transaction hashes, UTC timestamp, explorer URLs, and run hash without storing signing secrets.

### Field Delivery

- [ ] **DEMO-01**: Reviewer can complete the fixed evidence-to-strategy-to-existing-3D-to-audit path on the competition macOS machine in 3-5 minutes.
- [ ] **DEMO-02**: Demo has an offline cached fallback, current model card, test report, concise competition explanation, green local Mac gates, and one green macOS PR check that makes no cross-platform claim.

## v2 Requirements

### Hybrid Agent Runtime

- **AGENT-01**: Operator can run 125 synthetic representatives with bounded stance, goals, memory, relationships, and public-expression state for 42 days.
- **AGENT-02**: Baseline and candidate strategies use the same population and seed and produce reproducible, paired traces.
- **AGENT-03**: A bounded number of AI anchor decisions can affect deterministic propagation without 125 x 42 model calls or direct probability generation.
- **AGENT-04**: Results include mechanism explanations and P10/P50/P90 assumption-sensitivity bands rather than reality probabilities.

### Runtime-Driven Evolution Observer

- **VIS-01**: Operator can replay all 42 days of front state, Reverse voice, pressure/integrity, relation propagation, and key events from the new runtime.
- **VIS-02**: Observer labels unavailable channels instead of inventing data and verifies the runtime artifact before playback.
- **VIS-03**: Operator can compare baseline, candidate, and delta views and inspect a selected representative across supported platforms.

### Expansion

- **EXP-01**: Add further ZZZ crisis cases only after their evidence and transfer boundaries pass the same review gates.
- **EXP-02**: Add calibrated regional parameters only after direct multilingual regional evidence exists.
- **EXP-03**: Add non-macOS support, CI matrices, and cross-platform verification after the competition MVP is delivered.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Real player prediction | Synthetic agents are scenario representatives, not a sampled population |
| Automated chain deployment | Wallet and deployment actions require explicit human confirmation |
| Mainnet or real-value token mechanics | Competition proof uses testnet audit infrastructure only |
| Private social data ingestion | Project uses public data without community login |
| LLM-generated final probability | Final outputs are deterministic scenario indices and sensitivity ranges |
| Pre-competition cross-platform support or verification | The target deployment and platform evidence are limited to the current macOS demo machine and one macOS CI job; non-macOS jobs, portability, CI OS matrices, and cross-platform verification are post-competition iterations |
| Pre-competition hybrid Agent emergence | The competition path reuses the verified deterministic simulation and 3D replay baselines |
